## ✨ About This Project

This is my personal portfolio and the home of my work. It is built to showcase my projects, share what I'm learning, and help clients find me. The site is fully responsive, works without any frameworks, and is hosted for free on GitHub Pages.

> 💡 **Currently building:** a Mountain Trail landing page and new case studies for my portfolio.

---

## 🚀 Features

| | Feature | What it does |
|---|---|---|
| 📱 | **Responsive design** | Looks sharp on phones, tablets and desktops |
| 🍔 | **Mobile navigation** | Animated hamburger menu with keyboard support (Escape to close) |
| 🧭 | **Smooth scrolling** | Jump between sections without losing your place |
| 🗂️ | **Project showcase** | Featured work with tags, images, and live links |
| ✍️ | **Blog** | Category filters and search for posts |
| 🛠️ | **Services section** | Clear list of what I offer clients |
| 📬 | **Contact form** | Visitors can send enquiries straight to my inbox |
| 📄 | **Downloadable CV** | One click to download my latest CV |

## 🛠️ Getting Started

You don't need any build tools. Just open the project and go.

```bash
# 1. Clone the repository
git clone https://github.com/ireyefojuayo01/jeffery-nexus.git

# 2. Move into the folder
cd jeffery-nexus

# 3. Open index.html in your browser
#    or run a local server (recommended, for example with VS Code's Live Server)
```

## ⚙️ Customising

Before you deploy, update these placeholders:

- [ ] Project "Live Demo" and "GitHub" links in `index.html` (two projects still use `#`)
- [ ] Individual project links on the projects page, once it's built
- [ ] Your CV, saved as `cv.pdf` in the root folder

---

## 🌍 Deployment

This site is deployed with **GitHub Pages**:

1. Go to **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select **main** and **/ (root)**, then save

Your site goes live at `https://ireyefojuayo01.github.io/jeffery-nexus/`.
